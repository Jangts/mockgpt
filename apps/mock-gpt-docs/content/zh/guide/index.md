# Mock指南：搭建一个小可乐咖啡客服

本课程用一个轻量示例——**小可乐咖啡的智能客服**——逐步引导你掌握 MockGPT 的完整用法。不需要真实大模型、API key 或服务器，所有回复都由本地规则与生成器产生；学到的写法可以直接照搬到你自己的客服、测试或演示场景。

## 目标示例

我们要实现的客服能：

- 对「你好」返回欢迎语；
- 用关键词回答营业时间、地址、会员等业务问题；
- 点单时返回 JSON 菜单；
- 预约时给出工具调用提议；
- 下单时生成随机订单号与推荐；
- 把一大段需求压成一句「好的」摘要确认；
- 对长回复做流式分片，并接入标准模型客户端或独立服务。

## 环境准备

```sh
npm install @jangts/mock-gpt
```

调用方可以是前端或服务端。`generate()` 直接返回数据，不创建请求对象、不启动服务器；需要协议包装时再用内置 fetch 适配或 Node 服务。
